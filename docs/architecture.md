# StarAI · 十层架构与数学不变量规范

> 世界顶级 AI 内核 · 纯 JS 零依赖 · 可运行 / 可复现 / 可验证
> 作者：**晨星** ｜ 许可：MIT ｜ 自检：23/23 全绿

StarAI 不是从零造轮子，而是按"**零重写 · 集大成**"原则，把世界顶级数学、算法与预训练模型
**复用、组合、超越**后，凝练为一个可被数学不变量逐条交叉验证的内核。
每一层都有至少一条可被独立实现验证的**硬金标准（不变量）**——这是 StarAI 区别于"调包即交付"的根本。

## 二、各层设计要点（集大成而非重写）

### L1 数学基石（`src/core/la.js`）
- **Cholesky 分解** `A = L Lᵀ`：高斯推断与多元密度的数值基石，避免直接求逆。
- **Jacobi 旋转对称特征分解**：经典数值线代，machine-epsilon 级正交性。
  - ⚠️ **易错点（已修复）**：当 `app == aqq` 时 `θ=0`，朴素公式 `t = sign(θ)/(…)` 得 `t=0`
    导致零旋转、非对角元永不消去。修复为 `θ=0` 时 `t = sign(apq)`（±45° 旋转）。
- **SVD** 由 `AᵀA` 对称特征分解导出：`A = U S Vᵀ`，奇异值非负降序，是 Eckart–Young 最优截断的基础。

### L2 数值稳定原语（`src/core/num.js`）
- **logsumexp** `log Σeˣⁱ = m + log Σe^(xᵢ−m)`：防溢出，EM / softmax 之母。
- **稳定 softmax**：先减最大值再指数，行和恒为 1。

### L3 概率推断原语（`src/core/prob.js`）
- **多元高斯对数密度**（Cholesky 稳定）：`cholSolve` 返回 `z = Σ⁻¹ d`，马氏距离严格取 `dᵀz`（**非** `‖z‖²`）。
- **高斯 KL 散度**（解析）：`0.5( tr(Σ₁⁻¹Σ₀) + (μ₁−μ₀)ᵀΣ₁⁻¹(μ₁−μ₀) − k + ln|Σ₁| − ln|Σ₀| )`。
  - ⚠️ **已修复**：二次型同样误用 `zᵀz`，修正为 `diffᵀz`。

### L4 表示学习（`src/ml/pca.js`）
- 中心化 → `SVD(Xc)` → 主成分 = `V` 的行；得分 = `Xc·V`。
- 秩-k 重建 = `scores[:,:k] · V[:,:k]ᵀ`，与全 SVD 丢弃最小 k 个奇异值的结果一致（Eckart–Young）。

### L5 密度与聚类（`src/ml/gmm.js`）
- **EM 收敛性定理**：M-step 是 `Q(θ|θ_old)` 的精确极大元（纯 ML 协方差 `Σₖ = scatterₖ/Nₖ`），
  故观测数据对数似然 `L(θ)` 单调不降。空簇以单位阵兜底防退化。
- 可复现：`mulberry32` 注入种子，初始化确定。

### L6 深度监督学习（`src/ml/nn.js`）
- 2 层 MLP（tanh 隐藏 / sigmoid 输出），手写前向 + 反向传播。
- **梯度检验**：解析梯度 vs 中心差分数值梯度，`maxRelErr < 1e-6`。
- XOR 标志性测试：损失 < 0.1，预测全对。

### L7 序列与注意力（`src/ml/attention.js`）
- 缩放点积注意力 `softmax(QKᵀ/√d) V`，权重每行 Σ=1。

### L8 大模型集成（`src/integration/adapter.js`）
- **零重写·集大成**：直接复用 Hugging Face `transformers.js@3.0.0`（WebGPU/WASM），
  不重造 Transformer，把世界级预训练权重的推理能力接入本内核。
- `textGeneration`（如 `Xenova/distilgpt2`）、`embed`（如 `Xenova/all-MiniLM-L6-v2`）。
- 失败优雅降级并给出中文诊断。`embed` 输出的句向量可继续接入自研 `PCA`/`GMM` 做聚类——"组合超越"。

### L9 验证与不变量（`selftest.js`）
- 23 项不变量，全部以**独立参照实现**交叉验证（如 Gauss–Jordan 显式求逆验证马氏距离），
  杜绝"测试恰好放过 bug"。

### L10 交付与开源
- 单文件 `demo/starai.html`：浏览器内一键运行 23 项自检 + 交互可视化。
- 完整中文 `README.md`；MIT 许可；完整开源至 GitHub（署名 晨星）。

## 五、设计哲学（零重写 · 集大成 · 闭环交付）

1. **零重写**：不重造已被世界验证的数学（Cholesky、Jacobi、SVD、EM、Transformer）。
2. **集大成**：凡有更强现成方案立即替换自写——L8 直接对接 `transformers.js` 世界级预训练模型。
3. **唯一目标**：架构最先进（十层分解）、性能最强（machine-epsilon 级精度）、代码最优（零依赖单文件）、文档最全（不变量逐条可验证）。
4. **闭环交付**：可运行（Node + 浏览器）、可复现（固定种子）、可验证（23 项不变量）、开源至 GitHub（署名 晨星）。
